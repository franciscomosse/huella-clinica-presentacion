# Huella Clínica · presentación

Versión web, de solo lectura, de la presentación de **Huella Clínica** (Grupo 1 · MBA Salud).

Verla: https://franciscomosse.github.io/huella-clinica-presentacion/

- Se avanza tocando a la derecha (o con las flechas del teclado) y se vuelve tocando a la izquierda. En el celular, conviene girarlo.
- Los videos arrancan sin sonido; el botón «Sonido» lo activa.
